Supported Platforms
-------------------

This page describes platforms supported by the C# SNMP Library v13.

Supported runtimes
^^^^^^^^^^^^^^^^^^

 .NET 8.0 and later

Notes
^^^^^

If you need to target older frameworks, consider using the compatibility
branches in the project's repository. For details, see the project README

v12 requirements
^^^^^^^^^^^^^^^^

The v12 series targeted older .NET frameworks (including .NET Framework and
earlier .NET versions). v13 requires modern runtimes and does not
support those older frameworks. If you are still using v12, see the
:doc:`/tutorials/v13-migration` for migration guidance and the release
notes for v12 compatibility details.
